# Catalist

Серверная часть проекта Catalist: два сервиса на одном VPS, разворачиваются одним `docker compose`.

1. **Telegram-бот заявок** — приём заявок на дотацию ветеринарной помощи уличным кошкам.
2. **Модуль мерч-кодов** — генерация и проверка серийных номеров коллекционных изделий на поддомене (по умолчанию `code.catalist.world`). Основной сайт catalist.world размещён на Tilda и этим репозиторием не затрагивается.

## Быстрый старт

```bash
./deploy/deploy.sh        # первый запуск создаст .env и попросит его заполнить
nano .env                 # заполнить переменные (таблица ниже)
./deploy/deploy.sh        # сборка, запуск, health-check; он же — для обновлений
```

Вручную то же самое: `cp .env.example .env`, затем `docker compose build && docker compose up -d`.

Требования: docker с плагином compose; для модуля мерч-кодов — A-запись поддомена на IP сервера и открытые порты 80/443 (сертификат Let's Encrypt выпускается автоматически). Подробный порядок развёртывания — `docs/merch-module.md`, раздел «Развёртывание».

## Сервис 1: Telegram-бот заявок

Бот принимает заявки по команде `/apply`: последовательно запрашивает фото, процедуру, стоимость, ФИО, телефон, почту и комментарий, сохраняет заявку в SQLite и отправляет в группу рассмотрения (`REVIEW_CHAT_ID`) и администраторам. Решение — одобрить с указанием суммы или отклонить — уходит заявителю; при одобрении бот дополнительно предлагает поддержать проект.

| Команда | Описание |
|---|---|
| `/start` | приветствие |
| `/apply` | подать заявку на дотацию |
| `/help` | информация о программе |
| `/cancel` | отменить текущую заявку |

Токен выдаёт [@BotFather](https://t.me/BotFather); свой ID для `ADMIN_CHAT_IDS` можно узнать у [@userinfobot](https://t.me/userinfobot).

## Сервис 2: модуль мерч-кодов

Поддомен, на котором оператор генерирует серийные номера изделий, а покупатель проверяет подлинность и регистрирует изделие. QR-код сертификата ведёт на `https://<поддомен>/НОМЕР` — страницу с автопроверкой. Номер — 8 знаков Crockford Base32 с контрольным знаком; поля номера зашифрованы 128-битным ключом, который хранится только на сервере. Роли персонала (admin/config/production/ledger), вход через Google или по PIN, журналы выдачи, проверок и действий, дашборд `/admin`.

Документация:

- `docs/merch-module.md` — устройство и эксплуатация модуля (архитектура, формат номера, роли, API, runbook, бэкапы);
- `docs/google-oauth-setup.md` — настройка входа через Google;
- `CHANGELOG.md` — история релизов;
- `docs/worklog-merch.md` — журнал работ по внедрению.

Тесты модуля:

```bash
cd merch && python3 -m pytest
```

## Переменные .env

| Переменная | Сервис | Описание |
|---|---|---|
| `BOT_TOKEN` | bot | токен бота от BotFather |
| `ADMIN_CHAT_IDS` | bot | ID администраторов через запятую |
| `REVIEW_CHAT_ID` | bot | ID группы рассмотрения заявок |
| `MERCH_DOMAIN` | merch, caddy | поддомен модуля кодов (нужна A-запись на IP сервера) |
| `MERCH_PRODUCTION_PIN` | merch | PIN роли production; обязателен, ≥4 знаков |
| `MERCH_ADMIN_PIN` | merch | PIN роли admin; обязателен, ≥4 знаков, отличается от production |
| `MERCH_SERIAL_KEY` | merch | ключ шифрования номеров (32 hex); пустой — сгенерируется при первом старте, заполняется только при восстановлении из бэкапа |
| `MERCH_ADMIN_EMAILS` | merch | адреса, получающие роль admin при первом входе через Google |
| `GOOGLE_CLIENT_ID`, `GOOGLE_CLIENT_SECRET` | merch | ключи Google OAuth (см. `docs/google-oauth-setup.md`); пока не заданы — вход по PIN |
| `MERCH_VERIFY_PER_MIN`, `MERCH_REGISTER_PER_MIN`, `MERCH_ISSUE_PER_MIN` | merch | лимиты частоты запросов на IP (по умолчанию 30 / 10 / 60 в минуту) |
| `MERCH_VERIFYLOG_DAYS` | merch | срок хранения журнала проверок в днях (по умолчанию 365) |

## Структура репозитория

```
bot.py                  — телеграм-бот заявок
Dockerfile              — образ бота
requirements.txt        — зависимости бота
merch/
  app/                  — FastAPI-приложение: ядро номеров, хранилище, доступ
  web/                  — веб-интерфейс (проверка, выдача, журнал)
  tests/                — автотесты и эталонные векторы (vectors.json)
  Dockerfile            — образ модуля
deploy/Caddyfile        — reverse-proxy, автоматический HTTPS
docker-compose.yml      — сервисы bot, merch, caddy
docs/                   — документация модуля мерч-кодов
.env.example            — шаблон настроек
CHANGELOG.md            — история релизов модуля
```

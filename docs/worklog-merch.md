## Что осталось сделать вручную (не автоматизируется отсюда)

1. Создать A-запись DNS для поддомена (`code` → IP VPS).
2. Заполнить `.env` на сервере по `.env.example` (PIN-коды, домен, ключи).
3. Выполнить `docker compose build && docker compose up -d`.
4. Получить Google-credentials по инструкции `docs/google-oauth-setup.md` и внести в `.env`.
5. Добавить на Tilda кнопку «Проверка подлинности» со ссылкой на поддомен.
6. Забрать бэкап ключа `serial-key.backup.json` с сервера и сохранить в надёжном месте отдельно от бэкапов базы.

Осталось (полный чек-лист дня включения домена — `docs/domain-day.md`, шаги 3–8):

1. На сервере: `git pull` + `./deploy/deploy.sh` (обновление до 2.3.0), затем `docker compose exec merch python -m app.seed_batch --yes` — очистка тестовых данных и стартовая партия кодов.
2. В `.env`: удалить `MERCH_PUBLIC_URL=http://IP:8080`, сменить оба PIN-а (вводились по http); после подтверждения — убрать порт 8080 из `docker-compose.yml`/`deploy/Caddyfile` (правку внесём в репозиторий).
3. Google-вход (`GOOGLE_CLIENT_ID/SECRET`), письма с noreply@catalist.world (Brevo DKIM), кнопка на Tilda.
4. Фото Crystal White: сейчас стоит фото белой фигурки из прототипа — заменить URL у цвета в дашборде → Catalogue, когда появится фото хрустально-белой.
5. Включить ежедневный автобэкап: команда установки cron — в шапке `deploy/backup.sh`.
